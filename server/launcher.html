How to Play (plain English)

Solo — no server needed
  1. Double-click Play StrongBow.bat in the game folder.
  2. Click PLAY on the title screen. That’s it.
Host for friends (same Wi‑Fi / LAN)
  1. Double-click Host StrongBow.bat (or use Start Server below).
  2. Friends open the game, click SERVER, paste your LAN ws:// address.
  3. Use this panel to see who’s online, send gifts, or broadcast messages.

Joining someone else’s server? Run Play StrongBow.bat only — enter their server address in the game. You don’t need this control panel unless you’re hosting.
